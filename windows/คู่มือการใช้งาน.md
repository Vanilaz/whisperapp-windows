# คู่มือการใช้งาน Whisper (เวอร์ชัน Windows)

## มันคืออะไร ใช้ทำอะไร

**Whisper** เป็นแอป **พิมพ์งานด้วยเสียง** (dictation) ที่อยู่บน system tray (มุมล่างขวาข้างนาฬิกา)
วิธีใช้สั้น ๆ: **กดปุ่มลัดค้างไว้ แล้วพูด** — ปล่อยปุ่ม แอปจะแปลงเสียงเป็นข้อความ แก้คำผิด/ใส่เครื่องหมาย
วรรคตอนให้อัตโนมัติ แล้ว **วางข้อความนั้นลงในช่องที่เรากำลังพิมพ์อยู่ทันที** (แชท, เอกสาร, เบราว์เซอร์ ฯลฯ)

พูดง่าย ๆ คือ **"พูดแทนพิมพ์"** — คล้าย ๆ กับแอปดัง ๆ อย่าง Wispr Flow แต่ต่างตรงที่ Whisper
ใช้ API ที่เราควบคุมเอง (Groq) ไม่ผูกกับบริการเสียค่าสมาชิกรายเดือน

เบื้องหลังการทำงานเวลาพูดจบ 1 ครั้ง แอปจะทำ 4 ขั้นตอนนี้ให้อัตโนมัติ:

1. **อัดเสียง** ตอนกดปุ่มลัดค้างไว้ (ไมโครโฟนของเครื่อง)
2. **แปลงเสียงเป็นข้อความ** ผ่าน Groq Whisper (speech-to-text)
3. **ส่งข้อความให้ AI แก้ไข** (Groq Llama) — แก้คำที่ฟังผิด เติมวรรคตอน จัดประโยคให้อ่านง่ายขึ้น
4. **วางข้อความที่แก้แล้ว** ลงแอปที่กำลังใช้งานอยู่ (จำลองการกด Ctrl+V ให้)

โปรเจกต์นี้เดิมเป็นแอป **macOS** (เขียนด้วย Swift) ชื่อ WhisperApp — ตัวที่อยู่ในโฟลเดอร์ `windows/`
นี้คือเวอร์ชัน **Windows** ที่เขียนใหม่ด้วย .NET/WPF ให้ทำงานแบบเดียวกัน

---

## ก่อนใช้งาน ต้องมีอะไรบ้าง

- Windows 10 (1809 ขึ้นไป) หรือ Windows 11
- ไมโครโฟน
- **Groq API key** (ฟรี) — สมัครได้ที่ [console.groq.com](https://console.groq.com) แล้วสร้างคีย์
  ใน "API Keys" คีย์เดียวใช้ได้ทั้งแปลงเสียงและแก้คำผิด

---

## ติดตั้งยังไง

ตอนนี้ยังไม่มี installer สำเร็จรูปแจก ต้อง build เองก่อน (ครั้งเดียว):

```powershell
cd windows
./publish.ps1
```

จะได้ไฟล์ `windows/dist/Whisper.exe` — ดับเบิลคลิกเปิดได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม (self-contained)

ถ้าอยากได้ตัวติดตั้งจริง ๆ (มีทางลัด Start Menu, ตัวเลือก "เปิดแอปอัตโนมัติตอนเข้าเครื่อง", ปุ่ม
ถอนการติดตั้ง) ให้ลง [Inno Setup](https://jrsoftware.org/isinfo.php) ก่อน แล้วรัน `./publish.ps1`
อีกครั้ง จะได้ไฟล์ `Whisper-Setup.exe` เพิ่มมาด้วย

## เปิดใช้งานครั้งแรก

1. เปิด `Whisper.exe` — จะไม่มีหน้าต่างเด้งขึ้นมา (เป็นแอป tray) สังเกตไอคอนรูปไมค์ที่มุมล่างขวา
   ข้างนาฬิกา **ถ้าไม่เห็น ให้กดลูกศร "^" (แสดงไอคอนที่ซ่อนอยู่)** — Windows มักซ่อนไอคอนแอปใหม่
   ไว้ในนั้นก่อน ลากออกมาไว้นอก ๆ ได้ถ้าอยากให้เห็นตลอด
2. คลิกขวาที่ไอคอน → **Settings…** → ใส่ **Groq API key** ที่สมัครไว้ → กด **Save**
   (กด **Test** เพื่อเช็กว่าคีย์ใช้ได้จริง)
3. ครั้งแรกที่ลองอัดเสียง Windows จะถามสิทธิ์ **"อนุญาตให้แอปเข้าถึงไมโครโฟน"** → กด **อนุญาต**
   (ถ้าพลาดกดปฏิเสธไปแล้ว ไปเปิดเองได้ที่ Settings → Privacy & security → Microphone)

## วิธีใช้งาน

- **ปุ่มลัดเริ่มต้น: กด `Right Ctrl` ค้างไว้แล้วพูด** ปล่อยปุ่มเมื่อพูดจบ ข้อความที่แก้แล้วจะถูกวาง
  ลงในช่องที่ commit cursor อยู่ให้ทันที
  - ระหว่างพูด จะมีแถบคลื่นเสียงลอยขึ้นมาให้เห็นว่ากำลังอัดอยู่
  - หลังปล่อยปุ่ม จะเห็นสถานะ "Transcribing…" → "Fixing text…" → ข้อความที่ได้ (สั้น ๆ) ก่อนหายไป
- คลิกซ้ายที่ไอคอน tray ก็สั่งเริ่ม/หยุดอัดได้เหมือนกัน (เผื่อจำปุ่มลัดไม่ได้)

### ทำไมปุ่มลัดเริ่มต้นเป็น Right Ctrl ไม่ใช่ Fn เหมือน Mac?

เพราะคีย์บอร์ด Windows ปุ่ม Fn ถูก firmware ของคีย์บอร์ดจัดการเองก่อนส่งสัญญาณถึง Windows
แอปเลยไม่สามารถ "ดัก" ปุ่ม Fn ได้เหมือน Mac — เลยเลือก Right Ctrl แทน (เป็นปุ่มที่คนส่วนใหญ่
ไม่ค่อยได้ใช้อยู่แล้ว) เปลี่ยนได้เองใน Settings

### คลิกขวาที่ไอคอน tray จะเจอเมนู

| เมนู | ทำอะไร |
|---|---|
| Start/Stop Speaking | เริ่ม/หยุดอัดเสียง (เหมือนกดปุ่มลัด) |
| AI Correction | เปิด/ปิดขั้นตอนแก้คำผิดด้วย AI (ปิดแล้วจะได้ข้อความดิบจาก STT ตรง ๆ) |
| Language → Thai / Auto / English | บอกภาษาที่พูดให้ตัวแปลงเสียงรู้ล่วงหน้า (แม่นขึ้น) |
| Settings… | ใส่/แก้ Groq API key, เปลี่ยนปุ่มลัด, สลับโหมด hold/toggle |
| About Whisper | ข้อมูลเวอร์ชัน + เครดิตผู้พัฒนา |
| Quit | ปิดแอป |

### โหมดปุ่มลัด 2 แบบ (ตั้งได้ใน Settings)

- **Hold to talk (ค่าเริ่มต้น)** — กดค้างไว้ตอนพูด ปล่อยเมื่อพูดจบ
- **Toggle** — แตะ 2 ครั้งติดกันเพื่อเริ่มอัด แตะครั้งเดียวเพื่อหยุด (เผื่อพูดยาว ๆ ไม่อยากกดค้าง)

## แก้ปัญหาที่เจอบ่อย

**ไม่เห็นไอคอนแอปเลยหลังเปิดโปรแกรม**
กดลูกศร "^" ข้างนาฬิกาเพื่อดูไอคอนที่ซ่อนอยู่ก่อน ถ้ายังไม่เจอเลย และมีข้อความ error เด้งขึ้นมา
ให้คัดลอกข้อความนั้นมาให้ดู (เวอร์ชันล่าสุดจะเด้งกล่องข้อความบอก error แทนที่จะเงียบหายไปเฉย ๆ)

**พูดแล้วไม่มีอะไรถูกวาง (paste) ในบางแอป**
ข้อความที่แปลงได้จะยังอยู่ใน clipboard เสมอ กด **Ctrl+V** เองได้เลย — เรื่องนี้มักเกิดกับแอปที่เปิด
แบบ "Run as Administrator" (สิทธิ์สูงกว่า Whisper) ทำให้ Windows ไม่ยอมให้ Whisper จำลองปุ่มกดใส่ได้

**ไม่มีเสียงถูกอัด / ขึ้น "Microphone unavailable"**
เช็กสิทธิ์ไมโครโฟนที่ Settings → Privacy & security → Microphone ของ Windows ว่าอนุญาต Whisper
ไว้แล้ว และเช็กว่าเลือกไมค์ถูกตัวใน Windows Sound settings

**Settings → Test ขึ้นว่าคีย์ไม่ถูกต้อง**
เช็กว่าคัดลอกคีย์มาครบ ไม่มีช่องว่างติดมา และคีย์ยังไม่ถูกลบ/หมดอายุใน console.groq.com

## ข้อจำกัดที่ควรรู้ (เทียบกับเวอร์ชัน Mac)

- ไม่มีโหมดถอดเสียงแบบออฟไลน์ (local) — ต้องต่อเน็ตใช้ Groq เท่านั้น
- ไอคอนบน tray จะไม่เปลี่ยนรูปตามสถานะ (เหมือน Mac ที่เปลี่ยนไอคอนเป็นคลื่นเสียง/เครื่องหมายถูก ฯลฯ)
  สถานะทั้งหมดจะโชว์ที่กรอบลอยตรงกลางจอด้านล่างแทน
